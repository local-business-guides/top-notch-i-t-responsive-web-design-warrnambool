Key details to compare before you decide

The amount of work varies from one website to another. Use these points to understand what a proposal covers:

  • Work included: Confirm whether the scope is a new design, a redesign, WordPress setup, hosting, maintenance, SEO or a combination of services.
  • Timing: Project timing can change with the number of pages, requested features, how prepared the content is and the time needed for feedback and decisions.
  • Cost factors: Page count, design needs, functionality, content preparation and ongoing hosting or maintenance arrangements can affect the cost. Ask for a clear description of included work rather than comparing figures without context.
  • Support: Find out how routine edits are handled and where to turn if the site needs attention later.

Some terms you'll hear are straightforward. WordPress is a system for managing website content. Hosting keeps the site available online. SEO refers to work that helps search engines understand the pages. Responsive design means the site layout adapts to different screen sizes. These terms can help you compare what providers are proposing.
